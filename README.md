# Dundee Violet J.F.C. — Images

**Public** image host for the club website.

## Squad photos

Put player/coach photos in the `squad/` folder.

### Raw URL format (paste these into the website admin)

```
https://raw.githubusercontent.com/Whyme123444/dundeeviolet-images/main/squad/arran-smith.jpg
```

Change the filename for each person.

### How to upload the photos

1. Open https://github.com/Whyme123444/dundeeviolet-images
2. Click **Add file → Upload files**
3. Open or create the **squad** folder
4. Drop all `.jpg` files from the zip you got from Grok
5. Commit to **main**

Keep this repository **public** so the website can show the images.
